# 心律异常固件测试用例（Rhythm Abnormal Test Cases）

- 目标固件：`ecg-programme-tju-flex.electron-master`（ESP32-S3，N16R8）
- 测试目的：验证固件内置的心律异常识别链路能否正确检出各类异常，并评估误报率。
- 适用对象：硬件验收、算法回归、烧录后冒烟测试。

---

## 1. 测试范围

固件包含以下异常检测能力，本次测试逐一覆盖：

| 检测模块 | 判定逻辑 | 输出 |
|----------|----------|------|
| AI 异常分类 | INT8 1D-CNN（心律失常专家 exp7c） | `abnormal`, `confidence` |
| VF/VT 检测 | 5s 窗 DSP 特征 + 逻辑回归，连续 2 窗确认 | `vfAlarm` |
| AF 检测 | 10s RR 窗，CV + Shannon 熵 | `label=1`（AF 疑似） |
| 停搏 | RR ≥ 4.0s | `asystole=true` |
| 重度过缓 | 30s 窗平均 HR < 40 bpm | `bradycardia=true` |
| 过速 | 30s 窗平均 HR > 180 bpm | `tachycardia=true` |
| Flatline / 无信号 | 滤波后峰峰值持续低于阈值 | 并入统一报警 |

**统一报警**：以上任一路触发后，`updateUnifiedAlarm()` 要求连续异常达到确认窗口数才对外报 `abnormal=1`。

## 3. 固件操作命令速查

| 命令 | 作用 |
|------|------|
| `m` | 循环切换输入源：模拟 → 回放 → AFE → 模拟 |
| `n` | 回放模式下切到 **正常段**（MIT-BIH record 100） |
| `e` | 回放模式下切到 **异常段**（MIT-BIH record 106，VEB 室早密集） |
| `a` | 查看 AI 统计（总次数/异常次数/平均延迟/开关/最近置信度） |
| `r` | 重置滤波器 |
| `s` | 重置信号发生器 |
| `c` | 查看 CPU 频率 |
| `t` | 查看温度 |
| `l` | 查看 AFE 导联脱落状态（真实模式） |
| `DIAG AI 1` / `DIAG AI 0` | 开启/关闭 AI 推理 |

## 4. 测试信号源说明

### 4.1 当前固件内置信号源

| 信号源 | 内容 | 可测异常 |
|--------|------|----------|
| 模拟器 | 五高斯 P-QRS-T，75 bpm + 场景三噪声 | 仅阴性对照 |
| 回放段 0 | MIT-BIH 100（窦性正常），45s，500Hz | 阴性对照 |
| 回放段 1 | MIT-BIH 106（VEB 室早密集），45s，500Hz | AI 室早异常 |
| 真实 AFE | 外接人体/信号源 | 全部（需硬件） |

### 4.2 需要扩展的测试数据

以下异常类型**当前固件没有内置回放段**，需要先扩展测试数据（见第 6 节）：

- 室颤（VF/VT）
- 房颤（AF）
- 停搏（Asystole）
- 过速（Tachycardia）
- 过缓（Bradycardia）
- Flatline / 导联脱落

### 4.3 ⚠️ 合成信号与 AI 模型分布的差异（2026-08-20 实测）

`pc_tools/gen_rhythm_test_vectors.py` 生成的 `normal.csv` 是**数学合成高斯模板**，
与 exp7c AI 模型训练用的真实 MIT-BIH 数据形态差异较大。PC 端实测：

| 输入 | AI 异常率 | 说明 |
|------|-----------|------|
| 合成 `normal.csv`（高斯模板） | 45.8% | ❌ 不适合作为 AI 阴性对照 |
| 真实 MIT-BIH 100 段（固件内置） | 6.8% | ✅ 适合作为 AI 阴性对照 |
| 合成 `vf.csv` | 83.1% | ✅ VF 阳性检出明显 |
| 合成 `tachy.csv` | 0.0% | ⚠️ 规则快速心拍被模型视为正常（规则类检测依赖 RS 模块） |

**结论**：
- AI 模型阴性/阳性对照应优先使用**真实数据库回放数据**（`mitdb_normal_real.csv`、固件回放段 0/1）。
- 合成向量更适合验证 **VF/AF/停搏/过速/过缓等规则类算法**（这些不依赖 CNN 形态分布）。
- 固件上最可靠的验证路径仍然是：模拟器（阴性） + 回放段 0（真实正常） + 回放段 1（真实 VEB）。

## 5. 测试用例

> 结果列填写：✅通过 / ❌失败 / ⚠️存疑，并附实际观测值。

### TC-001 正常窦性心律（阴性对照）

- **目的**：确认正常信号不产生误报，作为所有阳性用例的基线。
- **前置条件**：固件已烧录，串口已连接。
- **输入信号**：模拟器（默认）或回放段 0（MIT-BIH 100）。
- **操作步骤**：
  1. 上电后确认串口打印 `ESP32-ECG-MONITOR 心电采集系统 v1.0`。
  2. 若当前不在模拟模式，按 `m` 切换到模拟模式。
  3. 持续观察 60 秒。
  4. 按 `a` 查看 AI 统计。
- **预期结果**：
  - BPM 稳定在 70~80（模拟器 75 bpm）。
  - AI 统计：异常次数 = 0，最近置信度 < 0.6。
  - 串口帧中 `abnormal=0`，无 VF/AF/停搏/过速/过缓报警。
  - SQI ≥ 0.8（模拟器）。
- **通过标准**：60 秒内 `abnormal` 保持 0。
- **实际结果**：____________

### TC-002 室性早搏 VEB（阳性，当前可直接执行）

- **目的**：验证 AI 心律失常专家能检出 VEB 密集段。
- **前置条件**：串口已连接。
- **输入信号**：回放段 1（MIT-BIH 106，VEB）。
- **操作步骤**：
  1. 按 `m` 切换输入源，直到进入回放模式（串口提示进入 REPLAY）。
  2. 按 `e` 切换到异常段（应打印 `>>> 回放: 异常段 (MIT-BIH 106, VEB) <<<`）。
  3. 持续观察至少 30 秒。
  4. 每 10 秒按一次 `a` 查看 AI 统计。
- **预期结果**：
  - AI 统计中异常次数应 > 0，或至少出现置信度显著抬升。
  - 若达到统一报警确认条件，串口帧 `abnormal=1`。
  - BPM 可能不规则（VEB 导致 RR 波动），但不一定触发 AF。
- **通过标准**：AI 统计异常次数 > 0；若 45 秒内从未出现异常窗口，判定为漏检。

### TC-003 室颤 VF/VT（阳性，需扩展数据）

- **目的**：验证 VF/VT 检测器在 5s 窗内识别混沌节律。
- **前置条件**：已按第 6 节扩展 VF 回放段（或真实 AFE 注入 VF 信号）。
- **输入信号**：VF 测试段（模拟正弦样混沌或 VFDB 数据），持续 ≥ 15 秒。
- **操作步骤**：

  2. 连续观察 20 秒。

- **预期结果**：
  - 前 5 秒为分析窗填充期，不判。
  - 5~15 秒内 `vfAlarm` 应为 1（连续 2 窗确认后），统一报警 `abnormal=1`。
- **通过标准**：在 VF 段开始后 15 秒内产生 VF 报警；正常段不误报。

### TC-004 房颤 AF（阳性，需扩展数据）

- **目的**：验证 AF 检测器能识别 RR 间期不规则。
- **前置条件**：已扩展 AF 回放段（或真实 AFE 注入 AF 信号）。
- **输入信号**：AF 测试段（RR 随机波动），持续 ≥ 20 秒。
- **操作步骤**：
  1. 切换到 AF 回放段。
  2. 连续观察 30 秒。
  3. 查看 AF 输出 `label`。
- **预期结果**：

  - 若 SQI 过低则门控为 `label=2`（不应误报 AF）。
- **通过标准**：AF 段 20 秒内 `label=1`；正常段 `label≠1`。

## 6. 扩展测试数据方案（VF/AF/停搏/过速/过缓）

当前固件只内置正常段和 VEB 段。要执行 TC-003 ~ TC-008，有以下两种路径：

### 路径 A：合成测试信号（推荐先做，不依赖外网）

在 `pc_tools/` 下新增脚本 `gen_rhythm_test_vectors.py`，生成以下信号（500Hz，float，单位 V）：

| 段 | 生成方式 | 时长 |
|----|----------|------|
| `vf` | 4~9Hz 调频正弦 + 幅度抖动（模拟 VF 混沌） | 20s |
| `af` | 正常 P-QRS-T 模板，RR 间期随机 0.5~1.2s | 30s |
| `asystole` | 10s 正常 + 6s 零线 + 10s 正常 | 26s |
| `tachy` | RR = 0.3s（200 bpm）规则心拍 | 40s |
| `brady` | RR = 2.0s（30 bpm）规则心拍 | 40s |
| `flatline` | 纯零线 + 极小白噪声 | 15s |

生成的文件可先用于：
1. **PC 端 AI 离线验证**：`python 07_pc_inference.py --source file --input <file>.npy`
2. **固件回放扩展**：按 `make_replay_data.py` 的格式转换成 C 数组，加入 `ecg_replay_data.h`，并在 `main.cpp` 中增加回放段切换命令。

### 路径 B：PhysioNet 公开数据库

- VF：MIT-BIH Malignant Ventricular Arrhythmia Database（VFDB）
- AF：MIT-BIH Atrial Fibrillation Database（AFDB）
- 用 `wfdb` 读取后重采样到 500Hz，沿用 `make_replay_data.py` 的 `fetch_segment` 流程。

## 8. 注意事项

1. **统一报警有确认窗口**：即使单窗口异常，也需要连续若干窗口才对外 `abnormal=1`，测试时应区分“内部异常计数”和“对外报警”。
2. **SQI 门控**：AF/停搏等规则报警在 SQI 过低时可能被抑制，这是设计行为，记录时需注明。
3. **信号量级**：回放数据单位为 V（1.05mV → 1.05V），与模拟器一致；若使用真实 AFE，注意 AFE 量级换算（VF v2 已做 mV/V 换算）。
4. **每次切换信号源后建议按 `r` 重置滤波器，避免上一个段的滤波器状态污染新段**。
