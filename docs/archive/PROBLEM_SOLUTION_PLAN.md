## 二、P1-3 运动鲁棒性：硬件锁死下的路线重选（最重要调整）

> **原首选"电极阻抗 ANC"已不可行**（需硬件改动）。硬件不动 = 无阻抗测量通道、无加速度计参考。**无参考信号的运动伪影抑制是更难的**——运动伪影频谱与 ECG 重叠（0.5–40Hz 内），文献首选 ANC 恰恰是因为它能"借参考信号分离重叠频谱"，无参考方法效果普遍打折。因此诚实下调预期：**目标是"检测+标记"为主、"软件去噪"为辅，而非完美滤除**。

### 分层方案（按务实程度排序）

| 层 | 方案 | 原理 | MCU 可行性 | 依赖 |
|---|---|---|---|---|
| **① 检测+标记（首选，最务实）** | 运动检测 + SQI 门控 + 数据不可信标记 | 检测运动伪影时段 → 标记该段数据不可信 → 冻结心率/AI 报警防误报 | ✅ 已有基础（`heartrate.cpp` 的 SQI/motion 逻辑），升级 | 无（纯固件） |
| **② 接触质量监测（免费）** | AD8232 AC lead-off 信号 | 100kHz/200nA 注入 + 同步检测，输出数字标志（LO±）→ 检测电极脱落/滑动，作为"接触不良"预警与 SQI 补充 | ✅ 片内已内置，只需读 LO± 引脚 | 无（纯固件） |
| **③ 软件去噪（中期）** | 小波去噪 / 卡尔曼 / 深度学习小模型 | 无参考信号直接去噪；对基线漂移/EMG 有效，对电极运动伪影有限 | ⚠️ 小波(块延迟)/卡尔曼(调参)可行；深度学习需 TFLite Micro INT8（项目有部署链） | 深度学习需真实运动数据 |
| ~~ANC（电极阻抗/加速度计）~~ | — | — | — | ❌ 硬件锁死，弃 |

### 落地建议

1. **先做 ①+②**：运动检测升级 + AD8232 lead-off 接触监测——投入小、纯固件、收益确定（防运动误报 + 接触不良预警），且"运动时段数据不可信"本身就是产品①的诚实 UX（心电图显示"运动伪影，信号质量低"）；
2. **③ 作为中期方向**：深度学习去噪复用项目已有 TFLite Micro 部署链，但**需先采集真实运动 ECG 数据**（当前训练数据全静息，且伦理 H6 阻塞）；小波/卡尔曼可先做 MCU 原型；
3. **诚实边界**：硬件不动时，"运动时显示干净心电图"这个产品目标的**上限**是有限的——无参考软件去噪无法达到 ANC 的效果（文献共识）。计划如实标注，不承诺"完美滤除运动伪影"。

## 三、其余问题方案摘要

- **P0-1 VF 采样率**：喂 `vfProcess` 前 2:1 抽取（250Hz）；验收 = 固件特征与 PC 250Hz 口径逐项一致 + 回放报警率对齐。
- **P0-2 AI 失配（固件+软件协同）**：修 `AI_HP_*` 系数 bug（fs=500→250 重算）+ 训练侧复刻**修正后**固件因果链 → 重训 exp7 → 部署链阈值重校准；验收 = 训练/部署链逐样本一致 + 患者级评估 + 残余失配报告（论文素材）。**顺序**：软件侧先复刻"修正后链"重训，固件侧同步修系数，两边对齐。
- **P1-1 心率 T 波**：补原始 PT 的 360ms 斜率判别（移植 rafaelmmoreira C 实现）+ RR 离群拒绝；验收 = LUDB F1 不劣于 0.774 + 真实 ECG 无 2× 值。
- **P1-2 报警决策层**：`alarm_manager` 五路分级仲裁（停搏/VF 最高优先）+ 融合级患者评估；验收 = 五路报警均点亮 abnormal_flag + 论文 H2/M9 融合指标。
- **P1-4 主循环+长程**：采样任务 + 双缓冲存储任务 + 独立网络任务 + LittleFS + 数据压缩；验收 = 帧间隔抖动 <±几百 µs + 长程容量达标。⚠️ 分区表改动需重新烧录（AGENTS.md 约束），先做"固件内压缩"不动分区。
- **P2-1 BLE 阶梯**：二进制帧 + 每连接事件批量 + `ESP_GATTS_CONF_EVT` 流控 + App 环形缓冲带序号；验收 = 真机波形平滑 + 丢包 <0.1%。
- **P2-2/P2-3/P2-4**：屎山/安全/论文，后置批次。

## 五、风险与诚实边界

1. 其余 v1~v3 风险不变（双核冻结物理上限、重训幅度不确定、BLE 实测确认、防回归）。
2. **运动伪影（P1-3）硬件锁死下上限有限**：无参考软件去噪无法达到 ANC 效果；"运动时显示干净 ECG"只能靠"检测+标记"诚实降级 + 软件去噪部分改善。这是硬件约束的物理/数学上限，不是软件能绕过的。
3. **深度学习去噪（P1-3 层③）依赖真实运动数据**（伦理 H6 阻塞）；当前只能用 NSTDB 合成噪声做离线原型（效果会高估）。
4. **电极舒适性 gap 仍在**：论文写柔性干电极、实物商用电极（凝胶），叙事缺口需论文里诚实标注。
5. 其余同 v3（电极阻抗 ANC 已删；加速度计 ANC 也因无板载 IMU 不可行，仅作"若未来硬件加 IMU"的备选备注）。
