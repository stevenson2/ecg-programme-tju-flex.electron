## 一、最高优先级：P0-2 训练-部署失配（复刻修正后链 + 重训 exp7）

### 1.1 确定"修正后固件链"（软件侧先定规格）

固件侧将修正 `AI_HP_*` 系数为 `butter(2, 0.5, fs=250)`（当前是 fs=500 设计，250Hz 链上有效截止 0.25Hz）。**软件侧先在 Python 用 scipy 算出正确系数，作为固件修正的规格**，同时复刻这条链：

```
500Hz → 梳状(10 抽头) → HP 0.05Hz + LP 40Hz → 2:1 抽取 → 因果 HP 0.5Hz(修正系数)
      → Z-score → 模型
```

> 注意：P0-2 决策（v1/v2 已定）是**因果重训**（非零相位窗口）。固件侧修系数后，AI 输入链应回到"因果 0.5Hz HP"（与 exp6-SGD 训练链一致），软件侧重训也要用这条因果链。

### 1.2 训练侧位级复刻（Python）

- 在 `preprocess.py` 把 filtfilt 链替换为上述**因果链**（复刻 biquad 系数与状态初始化）；
- 写一致性测试：同一测试向量，Python 复刻链 vs 固件 `filter.cpp` 公式逐样本比对（固件系数以修正后为准，先由 Python 算出并写入规格）。

### 1.3 重训 exp7

- 患者级 60/20/20（seed=42），SGD 超参沿用 exp6-SGD（lr=0.01 / Nesterov=0.9 / wd=1e-4 / patience=40）；
- 产出 `best_resnet_large_exp7.h5` + `train_history_exp7.csv`。

### 1.4 阈值重校准（软件侧）

- 部署链口径评估 exp7 的置信度分布，扫 θ∈{0.35,0.5,0.6,0.65,0.8} 给 R/P/F1；
- 产出 θ 表（固件侧改 `INFERENCE_THRESHOLD` 一个宏）。

### 1.5 残余失配报告（论文素材）

报告"因果 HP 相位畸变残余"量级（诚实面对物理上限），作为论文"部署陷阱"章节数据。

**产出**：`deploy_match/retrain_exp7_eval.json` + 失配→消融→重训→残余完整数据表 + AI 系数修正规格。

## 五、P1-3 运动鲁棒性：软件侧算法验证（无参考路线）

> 硬件锁死 → 无阻抗参考、无加速度计。软件侧做"无参考方法"的离线验证与选型。

1. **运动检测算法验证**：用 NSTDB（运动伪迹）+ 干净 ECG，验证/升级运动检测与 SQI 门控的阈值（运动时段检测的灵敏度/特异性）；
2. **软件去噪离线验证**：小波去噪 / 卡尔曼 / 深度学习小模型的 PC 原型对比（SNR、ECG 相关性、QRS 检测率），确定哪条值得上 TFLite Micro；
3. **产出**：运动检测阈值规格 + 去噪算法选型报告（`models/motion_denoise_eval.json`）。

**诚实边界**：无参考方法的去噪上限低于 ANC（文献共识）；软件侧只负责"选出最好的无参考方法 + 定量其上限"，不承诺完美滤除。

## 八、诚实边界

1. exp7 重训依赖"修正后系数"——软件侧先用 scipy 算出并写入规格，固件侧同步修，两边对齐后才有一致性；若固件侧暂未修系数，软件侧重训先用修正后链（未来固件对齐），并明确标注"固件系数待修"。

3. 深度学习去噪需真实运动数据（伦理 H6 阻塞），当前仅 NSTDB 合成离线原型。
4. 所有数字变更遵循 AGENTS.md §8（完美数字核查、可溯源、防回归）。
