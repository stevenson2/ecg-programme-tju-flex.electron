## 1. 方法（零训练移动设备方案）

| 项 | 设计 | 说明 |
|----|------|------|
| J 点近似 | R 峰 + **固定 50ms** | QRS ~100ms，峰近中点；无逐拍 J 点搜索（固件零成本） |
| ST80 | mean(J+60ms : J+100ms) − 基线 | J+80ms 窗口均值；基线 = PQ 段（R 峰前 80-40ms 均值） |
| R 峰检测 | 简化 Pan-Tompkins（带通 5-15Hz + 微分平方 + 150ms 积分 + 自适应阈值） | 与 `eval_rhythm_af_ptbxl.py` 同管线 |
| 金标准 | LUDB `.ii` 标注：`(`+`N`+`)` 段的 `)` = QRS 终点（J 点） | PhysioNet LUDB 医生手标 |
| 数据 | LUDB 200 条（500Hz）；PTB-XL records500 全量 | 本机 `ECG-Database/` 与 `PTB-XL_ECG/` |

## 2. 结果

### 2.1 LUDB J 点定位精度（200 条, 1,726 配对）

| 指标 | 值 |
|------|:---:|
| 自动/金标准峰数比（中位） | 1.22（自动略多，可接受） |
| J 点误差中位 | +2.0 样本（0.4ms） |
| **MAE** | **6.1 样本 = 1.2ms** |
| \|err\| ≤ 25ms | 90.0% |
| \|err\| ≤ 50ms | 98.4% |

**结论**：固定 50ms 偏移的 J 点近似与医生手标 QRS 终点误差 ~1ms 量级，远小于
ST80 窗口（40ms 宽）——**简化 ST 测量方案在定位层面可行**。

### 2.2 PTB-XL ST80 子类判别（记录级, 每记录 ≥3 拍平均）

| 组（导联） | n | ST80 中位 (µV) | vs NORM (µV) | AUC | Cohen's d |
|-----------|:---:|:---:|:---:|:---:|:---:|
| NORM（II） | 7,679 | +29 | — | — | — |
| **ASMI（V2, 前间壁）** | 1,020 | **+143** | +25 → +151 | **0.834** | **+0.75** |
| **STTC（II, 缺血/ST 改变）** | 1,976 | **−35** | +25 → −49 | 0.167（即 1−0.167=0.833） | **−0.74** |
| IMI（III, 下壁） | 1,426 | +23 | +25 → +34 | 0.477 | +0.11 |

**结论**：
- **前壁 MI 与缺血性 ST 改变判别强**（|AUC−0.5|≈0.33，|d|≈0.75）——单导联 ST80
  足以支撑"ST 抬高/压低"二类形态学信号，**模块 4 可行性确认**。
- **下壁 IMI 无判别（AUC 0.477）**：PTB-XL 的 IMI 标签为**慢性/陈旧记录**（含 Q 波
  但 ST 已恢复），ST80 无偏移是生理正确——**限制在标签粒度，非测量方法缺陷**；
  急性下壁 MI（ST 抬高）需急性期数据（如 STAFF III / 急诊 PTB 子集）或连续监测
  ST 变化量（delta-ST）路线。

## 3. 模块 4 建议（预研产出）

1. **ST80 测量可零训练上板**：J 点固定偏移 + PQ 基线 + 40ms 窗口，固件成本 ≈
   逐拍 3 次均值（与心率检测同量级）；R 峰由 `src/heartrate/` 提供。
2. **形态学输出定位**：ST80 作为**连续趋势信号**（分钟级 ST 变化量）比单次绝对值
   更稳健（个人基线归一化），与"异常检测 + 个人基线"架构一致。
3. **下壁短板**：依赖急性期数据验证（当前库无急慢性分层标签）；可先用 STTC 组的
   STE_（ST 抬高）代码做下壁急性近似（未来工作）。
4. **不入主结果**：本报告为预研（模块 4 立项依据），FINAL_RESULTS 表 6 不增行。
