# 真机 ECG 标注工具（误判 / 伪影）使用说明

位置：`benchmark_leadI_20261019/tools/annotator/`
- `ecg_annotator.html`：标注界面，单文件，不需要服务器。
- `ecg_annot_data.js`：4 段真机数据。由 `scripts/18_export_annot_data.py` 生成，必须和 HTML 放在同一目录。

## 1. 打开
双击 `ecg_annotator.html`，用 Chrome 或 Edge 打开即可，全程离线。

如果提示"未找到 ecg_annot_data.js"，在 WSL 里重新生成：
```bash
cd "/mnt/c/Users/cai/OneDrive/Desktop/Fe programme 25261/benchmark_leadI_20261019"
nice -n 19 python3 scripts/18_export_annot_data.py      # 约 4 秒，只读缓存，不跑模型
```

## 2. 画面里有什么
| 元素 | 含义 |
|---|---|
| 黑色曲线 | 250 Hz 显示信号，经过与固件相同的因果滤波链，并做了幅度归一 |
| ▼ 红色大三角 | 被**任一模型**判为 V 的拍（分数 ≥ 0.50），即"待标项" |
| ▼ 灰色小三角 | 新 AI QRS 触发（ai_qrs）检出、但没有被任何模型标记的拍 |
| 拍下方小字 `SH/D2/E5 + 数字` | student_hard / distill_v2 / exp5 的分数（×100），彩色表示超过阈值 |
| 竖虚线"报警 SH/D2/E5" | 该模型的报警进入时刻（固件规则：8/10 秒密度、保持 12 s、冷却 25 s） |
| 顶部彩条 | 报警持续时段：红 SH，蓝 D2，绿 E5 |
| 棕色半透明区 | 你标的伪影段 |
| 底部总览条 | 整段时间轴：黑框是当前窗口，点击可跳转 |

## 3. 标注流程（建议）
1. 填写"标注人"，选择会话。
2. 按 `J`（或 `Tab`）逐个跳到待标项，包括被标记的拍和报警进入，再按键给标签：

   | 按键 | 标签 | 什么时候用 |
   |---|---|---|
   | `V` / `1` | 真室早 (V) | 确实是室性早搏 |
   | `N` / `2` | 正常 (N) | 是真实心拍，但不是 V（模型判错了） |
   | `F` / `3` | 误判 | 检测本身就错了：不是心拍（T 波、噪声尖峰等），或报警是误报 |
   | `A` / `4` | 伪影 | 运动、电极接触等伪影造成 |
   | `U` / `5` | 不确定 | 判断不了，统计时排除 |
   | `Del` / `0` | 清除标签 | |

   - 打完标签会自动跳到下一个待标项。
   - 报警竖线也要标：真 V 事件标 `V`，误报标 `F` 或 `A`。
3. **伪影段**：在波形上按住左键拖动即可框出起止时间。右键点伪影段可以删除。
4. **未被标记的拍**也可以标：
   - 单击拍选中后按键；
   - `.` / `,` 逐拍前后移动，包括所有拍。
5. **漏检的 V**（检测器没出拍）：`Alt` + 单击该位置补一个拍，再按 `V`。右键可删除。
6. 浏览：
   - `←` / `→` 平移半屏，`PgUp` / `PgDn` 平移整屏，滚轮也可平移。
   - `Ctrl` + 滚轮或 `+` / `-` 调幅度。
   - `[` / `]` 或"窗长"下拉框调窗口长度，默认 10 s。
7. 勾选"列表只看未标"，可以快速找到漏掉的项。

## 4. 保存
- 每次操作都会**自动保存**到浏览器 localStorage。同一台电脑、同一个浏览器再打开会自动恢复。
- **导出 JSON**：完整标注，交给分析脚本用。请定期导出备份，因为清除浏览器数据会丢失 localStorage。
- **导出 CSV**：方便人工查看。每行格式：会话、类型（beat / manual_beat / alarm / artifact）、模型、样本号（250 Hz）、时间、结束时间、标签。
- **导入 JSON**：换电脑或换浏览器后恢复标注；会覆盖同名会话。

建议把导出的 JSON 放到 `benchmark_leadI_20261019/results/labels/`。

## 5. 重算指标
```bash
python scripts/19_metrics_from_labels.py results/labels/ecg_labels_姓名_时间.json
# 可选：--unlabeled-unflagged exclude   不把"未标且未被标记"的拍当作正常
```
输出文件为 `results/real_label_metrics.csv`，同时在屏幕打印表格。每个会话、每种导联（leadI / wearable / ALL）、每个模型都会给出两套结果：
- `all`：不排除伪影；
- `excl_art`：排除伪影段内的拍和报警，并从总时长中扣除伪影时间。

指标包括：
- 拍级 Se、PPV：真值 V = 标 V 的检出拍 + 补的漏检 V；
- FP/h：报警进入被标为 N / 误判 / 伪影的次数，除以时长。

未标的报警按自动规则判定：前 10 s 内没有标 V 的拍，就算误报。`n_alarm_auto` 列给出这样判定的报警个数。

## 6. 注意
- 拍位置来自新的宽松 AI 触发：`ECG_AI_PERMISSIVE_QRS=1`，PC 端用 `tools/hr_host` 的 mode 2 回放。报警时刻按阈值 0.50 预先算好。
- 真机数据约 100 Hz，与训练数据分布差异很大：Lead I 会话里几乎每一拍都被至少一个模型标记，所以待标项较多（约 150 个/段）。
  - 可以先标完报警，再用 `J` 逐个标拍。
  - 多数正常拍可以连续按 `N` 快速处理。
